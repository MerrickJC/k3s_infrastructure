# Certificates
Currently using cloudflare tunnels does not require TLS certificates, as cloudflare provides tls encryption for us. Hence, the certificates are commented out. The certificates are added here so that they can be utilised in the future when needed and to prevent too much work-around having to re-add them during migration.

If you deploy without a cloudflare tunnel (and therefore do not have TLS encryption provided for you) then you will need to uncomment these certificates
